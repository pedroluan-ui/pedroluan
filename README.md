# TalentHub Currículos

Aplicação web acadêmica para gestão de currículos, desenvolvida com Next.js App Router, Tailwind CSS e componentes no padrão shadcn/ui.

## Funcionalidades parciais

- Landing page responsiva com benefícios do sistema.
- Lista de currículos mockados com cards de resumo.
- Busca em tempo real por nome ou cargo.
- Página dinâmica de detalhes do currículo.
- Cadastro com React Hook Form, Yup, máscaras e notificações Sonner.
- Campos dinâmicos para experiências profissionais e formações acadêmicas.
- Persistência local via `localStorage` e imagens públicas em `public/avatars`.

## Stack

- Next.js + App Router
- Tailwind CSS
- shadcn/ui (componentes locais inspirados no padrão oficial)
- React Hook Form + Yup
- React Input Mask Next
- Sonner
- React Icons

## Como executar

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.
